# Built-in Acoustic Reference Samples

This folder contains pre-calibrated reference audio recordings ready for upload and testing with the AcousticIQ platform.

## Available Samples

| Filename | Machine Class | Type | Acoustic Characteristics |
| :--- | :--- | :--- | :--- |
| `1_valve_normal_sample.wav` | Valve | Normal | Clean pneumatic valve stroke and solenoid seating. |
| `2_valve_anomaly_sample.wav` | Valve | Anomaly | High-frequency acoustic leak hiss and seating chatter. |
| `3_pump_normal_sample.wav` | Pump | Normal | Constant centrifugal pump rotation and 50 Hz power line harmonics. |
| `4_pump_anomaly_sample.wav` | Pump | Anomaly | Impeller cavitation bursts and mechanical bearing race friction. |
| `5_fan_normal_sample.wav` | Fan | Normal | Aerodynamic blade pass frequency and stable airflow turbulence. |
| `6_fan_anomaly_sample.wav` | Fan | Anomaly | Blade aerodynamic stall and unbalance vibration flutter. |
| `7_slider_normal_sample.wav` | Slider | Normal | Smooth reciprocating linear guide slide motion. |
| `8_slider_anomaly_sample.wav` | Slider | Anomaly | Mechanical rail friction squeal, scoring, and binding transients. |

You can drag and drop any of these files into the upload box on the **Acoustic Analysis** page or click the built-in reference buttons directly in the dashboard UI!
